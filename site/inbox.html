Siri

Set up Siri

Say “Hey Siri, Idea”, speak it, and it lands here. A Shortcut on your iPhone does the sending, with a token only it holds.

Checking…

Header value — shown once. Copy it into the Shortcut now.

URL

  1. Open the Shortcuts app and tap +.
  2. Tap the name at the top and call it Idea — that is what you will say to Siri.
  3. Add the action Dictate Text.
  4. Add Get Contents of URL. Paste the URL above. Tap the arrow to show more, then set Method to POST.
  5. Under Headers, add one: key Authorization, value the header value above (it starts Bearer ibx_).
  6. Set Request Body to JSON and add a Text field: key text, value the Dictated Text variable.
  7. Add Get Dictionary Value: get the value for key message in Contents of URL.
  8. Add Speak Text (or Show Result) with that Dictionary Value.
  9. Done. Say “Hey Siri, Idea”, speak, and Siri answers “Saved: …”.

Lost the phone, or pasted the token somewhere it should not be? Replace it here and the old one stops working at once.
