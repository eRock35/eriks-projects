Shortcuts

Every Shortcut below uses Get Contents of URL with a header Authorization whose value is your phone token’s header value (it starts Bearer ibx_). Set Request Body to JSON where there is a body.

Idea “Hey Siri, Idea”
  1. New Shortcut, named Idea. Add Dictate Text.
  2. Get Contents of URL: the ideas URL, Method POST, the header, JSON body: text = Dictated Text.
  3. Get Dictionary Value message from Contents of URL, then Speak Text. Siri says “Saved: …”.
Do this share sheet: text, a link, a picture
  1. New Shortcut, named Do this. Tap ⓘ and turn on Show in Share Sheet. In the first action, Receive Images, Text, Rich text, URLs, Safari web pages from Share Sheet; if there is no input, Stop and Respond.
  2. Get Images from Input (Shortcut Input). If Images has any value: Resize Image to width 1280; Convert Image to JPEG, Quality 60%, Preserve Metadata off; Base64 Encode, Line Breaks None; Get Contents of URL: the capture URL, POST, the header, JSON: source = share, image = Dictionary {mediaType = image/jpeg, data = Base64 Encoded}.
  3. Otherwise: Get URLs from Input. If URLs has any value: Get Details of Safari Web Page (Name) from Shortcut Input, then Get Contents of URL (capture URL, POST, header) with source = share, url = URLs, title = Name.
  4. Otherwise: Get Text from Input, then Get Contents of URL (capture URL, POST, header) with source = share, text = Text. End If twice.
  5. Get Dictionary Value message from If Result, then Show Notification.

Messages: long-press a bubble, More, tick it, share, Do this. Mail: select the text first. For a version that takes a spoken line too, add Dictate Text first and a note = Dictated Text field to each body; only that note is ever read as your instruction.

Snap this the Action button
  1. New Shortcut, named Snap this. Add Take Screenshot.
  2. Resize Image to width 1280; Convert Image to JPEG, Quality 60%, Preserve Metadata off; Base64 Encode, Line Breaks None.
  3. Get Contents of URL: the capture URL, POST, the header, JSON: source = screen, image = Dictionary {mediaType = image/jpeg, data = Base64 Encoded}.
  4. Get Dictionary Value message, then Show Notification.
  5. Settings › Action Button › Shortcut › Snap this.

It sends whatever is on screen, so it lives on the Action button only - not Back Tap, which fires by accident. A screen showing a code, a card, a password, a bank or a medical page is deleted unread. If it says the picture is too big, lower the quality.

Errand “Hey Siri, Errand”
  1. New Shortcut, named Errand. Add Dictate Text.
  2. Get Contents of URL: the capture URL, POST, the header, JSON: source = siri, note = Dictated Text.
  3. Get Dictionary Value message, then Speak Text. Siri reads all of it back, so a misheard day is heard.
  4. In ⓘ, turn on Show on Apple Watch, and allow it to run when locked if your iOS offers that.
Reply “Hey Siri, Reply”
  1. New Shortcut, named Reply. Get Contents of URL: the answers URL, Method GET, the header.
  2. Get Dictionary Value next from Contents of URL. If Dictionary Value does not have any value: Speak Text “Nothing is waiting on you.”, Stop This Shortcut. End If. Set Variable Next.
  3. Get Dictionary Value question from Next, Speak Text. Get Dictionary Value choices from Next, Choose from List (prompt: the question).
  4. Text: https://strongtechnicalconsulting.com/api/inbox/[id from Next]/reply. Get Contents of URL: that Text, POST, the header, JSON: k = [k from Next], choice = Chosen Item.
  5. Get Dictionary Value add from Contents of URL, Set Variable Add. If Add has any value: If type of Add is event: Get Dates from Input for start and for end, then Add New Event - Title title, Start Date, End Date, Location location, Notes notes, Alert nearest alertMinutes (1 hour before by default). Otherwise: Get Dates from Input for due, then Add New Reminder - title, Remind Me At that date, Notes notes. End If. Speak Text “Added”.
  6. Otherwise: Get Dictionary Value message, Speak Text. End If.

A menu, never typed text - so a code or a sentence cannot travel by it. Nothing is added to your calendar unless you pick the add choice, and the phone does the adding: no iCloud password is anywhere else.

Any answer? “Hey Siri, Any answer?”
  1. New Shortcut, named Any answer?. Get Contents of URL: the answers URL, GET, the header.
  2. Get Dictionary Value say, then Speak Text. It speaks the question waiting on you, or the newest answer.
Add it answering on this page
  1. Pick the add choice on an ask above (it is the filled button).
  2. An event shows Add to Calendar: tap it, and Calendar opens the event; tap Add.
  3. A reminder shows Copy it for Reminders: paste it into a new reminder, or answer from Reply on the phone instead and it is added for you.
