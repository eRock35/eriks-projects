    How this works

    • Apple turns away stock checks from servers - it answered every one we sent from Google’s network with a block page - so our server doesn’t ask it. “See this model on Apple” opens Apple’s page for your exact model, where Check availability is one tap, and “Check from my iPhone” shows how to build a Shortcut that asks Apple from your phone instead.
    • Best Buy is a live check through Best Buy’s official Products API, when it is connected. Until then it is a link.
    • AT&T, Verizon and T-Mobile are links. They have no public stock service and block automated checks, so we never ask them anything. Tap through, then mark what you saw so you remember when you last looked.
    • Watching re-checks Best Buy, so it needs Best Buy connected. It runs in this tab only, while it is open and on screen. There is no server timer and no push - close the tab and it stops.
    • Your ZIP, picks and notes stay on this device. Nothing is stored on our side, and there is no AI in here.

    Not affiliated with Apple, Best Buy, AT&T, Verizon or T-Mobile. Stock changes fast - a store’s own page always has the last word.

    Check Apple from your iPhone

    Apple turns away checks from servers like ours, but a phone on a home or mobile network is a person. Build this once in the Shortcuts app and your iPhone asks Apple itself.

    Part · near

    Not tested on a phone yet, and Apple may change the shape of its answer. If this stops working, “See this model on Apple” still does.

    1. In Shortcuts, tap + and add a Text action. Paste this into it:

      This link needs your ZIP. Add it in the ZIP box first - it stays on this device.

    2. Add Get Contents of URL. It takes the Text above; leave Method on GET.

    3. Add Get Dictionary Value four times, each taking the one before: get the value for body, then content, then pickupMessage, then stores.

      Shortcuts may also take the key path body.content.pickupMessage.stores in one Get Dictionary Value. If that comes back empty, use the four.

    4. Add Repeat with Each on those stores. Inside the repeat:

      • Get Dictionary Value partsAvailability from Repeat Item, then from that, then pickupDisplay.
      • If that value is available: get storeName from Repeat Item and pickupSearchQuote from the value, put both in a Text, and Add to Variable Found.

      Or as key paths from Repeat Item: partsAvailability..pickupDisplay and partsAvailability..pickupSearchQuote.

    5. After the repeat, add If Found has any value:

      • Show Notification “iPhone Duo in stock: Found”, then Open URLs:
      • Otherwise: Show Notification “No iPhone Duo pickup near yet” - or leave it empty in the scheduled version, so it only speaks up when it finds one.

    6. Make it automatic: Shortcuts → Automation → + → Time of Day, pick a time, Daily, Run Immediately, then choose this shortcut. Add a few - morning, lunchtime, evening - to check several times a day.

    Building this sends nothing to Duo Hunt: the ZIP goes from this page into your Shortcut, and from your phone straight to Apple.
